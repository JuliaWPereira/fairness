# Fairness in Credit Risk Analysis

This repository contains a comprehensive project focused on fairness, bias mitigation, and regulatory context in credit risk modeling. It includes Jupyter notebooks, LaTeX documentation, datasets, and visualizations to guide practitioners and researchers through the process of understanding, evaluating, and improving fairness in credit scoring models.

## Project Structure

- **notebooks/**: Step-by-step Jupyter notebooks covering data preparation, bias exploration, fairness baseline, bias mitigation, and fairness insights.
- **data/**: Raw and processed datasets, including the South German Credit dataset and supporting files.
- **reports/**: Visualizations and analysis outputs generated by the notebooks.
- **requirements.txt**: Python dependencies for running the notebooks.

## How to Use

1. **Install Dependencies**
   - Create a Python environment (e.g., using `venv` or `conda`).
   - Install required packages:
     ```bash
     pip install -r requirements.txt
     ```
2. **Run Notebooks**
   - Open the notebooks in the `notebooks/` folder using Jupyter or VS Code.
   - Follow the step-by-step instructions, checklists, and explanations in each notebook.
3. **Compile LaTeX Report**
   - Use a LaTeX editor (e.g., Overleaf, TeXShop) to compile the main report in `IA___Projeto___Final__with_comments_/`.
   - Ensure all referenced files and bibliography are included.

## Notebooks Overview

- **01_data_prep.ipynb**: Data loading, cleaning, and feature importance analysis.
- **02_bias_exploration.ipynb**: Exploratory data analysis focused on bias detection.
- **03_fairness_baseline.ipynb**: Establishes baseline fairness metrics and commentary.
- **04_bias_mitigation_enriched.ipynb**: Applies and evaluates bias mitigation techniques.
- **05_fairness_insights.ipynb**: Summarizes findings and actionable insights.

## Key Features

- Regulatory context and best practices for fairness in credit risk modeling.
- Actionable checklists and guidelines for practitioners.
- Harmonized tables and visualizations for clarity.
- Troubleshooting tips for LaTeX compilation and BibTeX usage.
